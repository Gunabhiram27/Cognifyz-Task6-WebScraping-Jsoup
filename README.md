# Task 6 – Web Scraping with Jsoup 🌐

A simple Java-based web scraper that fetches text content from a public website using Jsoup.

## 📌 Features
- Connects to a public blog or quotes website
- Scrapes and displays content like quotes or titles
- Uses HTML tag-based selectors

## 🛠️ Technologies Used
- Java
- Maven
- IntelliJ IDEA
- Jsoup

## 🚀 How to Run
1. Clone or download the repo
2. Open in IntelliJ
3. Run `WebScraper.java` from the `com.cognifyz` package
